# Aplicativo de Cinema - Grupo 12

## Objetivo
Aplicativo mobile para centralizar trailers, sinopses, avaliações, programação de cinemas locais e compra de ingressos[cite: 2].

## Como rodar o projeto[cite: 1]

**Frontend:**
1. Abra o terminal e digite: `cd frontend`
2. Inicie o app: `npx expo start`

**Backend:**
1. Abra o terminal e digite: `cd backend`
2. Inicie o servidor: `npm start`
